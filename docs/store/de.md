## Beschreibung (4000)

```
Odete ist eine Entwicklungsumgebung, die komplett auf deinem iPad läuft. Keine Remote-Sitzung, kein Browser-Tab auf den Rechner von jemand anderem: Editor, git-Repository, Terminal, Paketmanager und Webserver liegen alle auf dem Gerät in deinen Händen.

Heißt: Sie funktioniert im Flugzeug, in der U-Bahn und überall dort, wo kein Netz hinkommt.

EDITOR
• Syntax-Highlighting von tree-sitter, für JavaScript, TypeScript, JSX, Swift, CSS, HTML, JSON, YAML, Markdown und SQL
• Git-Markierungen am Rand — tippe eine an, um den hunk zu öffnen und zu verwerfen
• Vervollständigung aus den Wörtern deiner Datei, den Pfaden im Projekt und Snippets
• Lint beim Tippen, dazu echte Syntaxfehler von esbuild
• Tabs, Split View, diff-Ansicht und Viewer für Bilder, PDFs und SQLite-Datenbanken
• Ungespeicherte Arbeit überlebt das Schließen der App

GIT, DAS ECHTE
• Ein echtes Repository pro Projekt, auf libgit2 — kein Wrapper um eine Web-API
• Stage pro Datei oder pro hunk, commit, branch, merge mit Konfliktauflösung, stash
• Klonen und push über HTTPS, blame und Historie pro Datei
• GitHub pull requests in der App: einen öffnen, lesen, CI prüfen, kommentieren, mergen
• Die commit-Message aus dem gestagten diff schreiben, mit einem Tipp

TERMINAL
• Eine echte Shell: Pipes, Umleitungen, &&, ||, ;, &, Variablen, Job-Steuerung, History, Tab
• npm install gegen die echte Registry, mit semver-Auflösung und echter Lock-Datei
• npm run dev, node, npx, git und die üblichen ls, cat, grep, find
• Alles, was einen Port öffnet, wird ein Job, den du auflisten und killen kannst

PREVIEW
• Dein Dev-Server, gerendert im Bereich neben dem Code, neu geladen bei jedem Speichern
• Vite, Astro, Next und Nest
• Viewports für iPhone, iPad und Desktop, die Konsole der Seite, ein Tipp nach Safari

EIN CODING-AGENT, ZU DEINEN BEDINGUNGEN
• Bring deinen eigenen Account mit: Claude, Codex, Grok oder jeden OpenAI-kompatiblen Endpoint
• Er liest deine Dateien, führt Befehle aus und ändert Code — aber jede Änderung kommt als Patch
• Nimm ihn an, lehn ihn ab oder nimm ihn hunk für hunk an. Ein Checkpoint vor jedem Zug
• Chat liest, Plan schreibt einen Plan, Build ändert. Du entscheidest, wie weit er darf
• Kein Odete-Account und keine Odete-Server: Er spricht direkt mit deinem Anbieter

SWIFT
• Eine SwiftUI-Teilmenge, interpretiert und als echtes SwiftUI gerendert, live beim Tippen
• Oder ein Swift-Playground-Paket bauen und es zum Kompilieren in Swift Playgrounds öffnen

FÜNF SPRACHEN
Português, English, Deutsch, Français und Español — die Screens, die Terminal-Ausgabe,
die git-Meldungen und die Sprache, in der der Agent antwortet. Standardmäßig folgt Odete
deinem iPad, und in den Einstellungen schaltet es sofort um.

DEINE DATEIEN GEHÖREN DIR
Projekte liegen in der „Dateien“-App unter Odete oder in iCloud Drive. Öffne sie in Working Copy,
in Swift Playgrounds, in was auch immer. Kein Lock-in, kein Sync-Dienst von uns, keine Telemetrie
und nichts, wofür du dich anmelden musst.
```
