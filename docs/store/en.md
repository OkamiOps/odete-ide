## Description (4000)

```
Odete is a development environment that runs entirely on your iPad. Not a remote session, not a browser tab pointed at someone else's machine: the editor, the git repository, the terminal, the package manager and the web server all live on the device in your hands.

Which means it works on a plane, on the subway, and anywhere the signal doesn't reach.

EDITOR
• Syntax highlighting by tree-sitter, for JavaScript, TypeScript, JSX, Swift, CSS, HTML, JSON, YAML, Markdown and SQL
• Git marks in the margin — tap one to open the hunk and discard it
• Completion from the words in your file, the paths in your project, and snippets
• Lint as you type, plus real syntax errors from esbuild
• Tabs, split view, diff view, and viewers for images, PDFs and SQLite databases
• Unsaved work survives closing the app

GIT, THE REAL ONE
• A real repository per project, on libgit2 — not a wrapper around a web API
• Stage by file or by hunk, commit, branch, merge with conflict resolution, stash
• Clone and push over HTTPS, blame, and history per file
• GitHub pull requests inside the app: open one, read it, check CI, comment, merge
• Write the commit message from the staged diff with one tap

TERMINAL
• A real shell: pipes, redirects, &&, ||, ;, &, variables, job control, history, Tab
• npm install against the real registry, with semver resolution and a real lock file
• npm run dev, node, npx, git, and the usual ls, cat, grep, find
• Anything that opens a port becomes a job you can list and kill

PREVIEW
• Your dev server, rendered in a pane next to the code, reloading every time you save
• Vite, Astro, Next and Nest
• iPhone, iPad and desktop viewports, the page's own console, and one tap to Safari

A CODING AGENT, ON YOUR TERMS
• Bring your own account: Claude, Codex, Grok, or any OpenAI-compatible endpoint
• It reads your files, runs commands and edits — but every edit arrives as a patch
• Accept it, reject it, or accept it hunk by hunk. A checkpoint before every turn
• Chat reads, Plan writes a plan, Build edits. You choose how much it may do
• No Odete account and no Odete servers: it talks to your provider directly

SWIFT
• A SwiftUI subset, interpreted and rendered as real SwiftUI, live as you type
• Or make a Swift Playground package and open it in Swift Playgrounds to compile

FIVE LANGUAGES
Português, English, Deutsch, Français and Español — the screens, the terminal output,
the git messages and the language the agent answers in. It follows your iPad by default,
and changes instantly in Settings.

YOUR FILES ARE YOURS
Projects live in the Files app under Odete, or in iCloud Drive. Open them in Working Copy,
in Swift Playgrounds, in anything. No lock-in, no sync service of ours, no telemetry, and
nothing to sign up for.
```
