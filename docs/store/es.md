## Description (4000)

```
Odete es un entorno de desarrollo que corre entero en tu iPad. No es una sesión remota ni una pestaña del navegador apuntando a la máquina de otro: el editor, el repositorio git, el terminal, el gestor de paquetes y el servidor web viven en el dispositivo que tienes en las manos.

O sea que funciona en un avión, en el metro, y en cualquier lugar donde no llega la señal.

EDITOR
• Resaltado de sintaxis con tree-sitter, para JavaScript, TypeScript, JSX, Swift, CSS, HTML, JSON, YAML, Markdown y SQL
• Marcas de git en el margen — toca una para abrir el hunk y descartarlo
• Autocompletado a partir de las palabras del archivo, las rutas del proyecto y snippets
• Lint mientras escribes, más errores de sintaxis reales de esbuild
• Pestañas, vista dividida, vista de diff, y visores de imagen, PDF y bases de datos SQLite
• Lo que no guardaste sobrevive al cierre de la app

GIT, EL DE VERDAD
• Un repositorio real por proyecto, sobre libgit2 — no un wrapper de una API web
• Stage por archivo o por hunk, commit, branch, merge con resolución de conflictos, stash
• Clone y push por HTTPS, blame e historial por archivo
• Pull requests de GitHub dentro de la app: abre uno, léelo, revisa el CI, comenta, haz merge
• Escribe el mensaje del commit a partir del diff en stage con un toque

TERMINAL
• Una shell de verdad: pipes, redirecciones, &&, ||, ;, &, variables, control de jobs, historial, Tab
• npm install contra el registro real, con resolución semver y un lock file real
• npm run dev, node, npx, git, y los de siempre ls, cat, grep, find
• Cualquier cosa que abra un puerto se vuelve un job que puedes listar y matar

PREVIEW
• Tu dev server, renderizado en un panel junto al código, recargando cada vez que guardas
• Vite, Astro, Next y Nest
• Viewports de iPhone, iPad y escritorio, la consola de la propia página, y un toque para abrirla en Safari

UN AGENTE QUE PROGRAMA, EN TUS TÉRMINOS
• Trae tu propia cuenta: Claude, Codex, Grok, o cualquier endpoint compatible con OpenAI
• Lee tus archivos, ejecuta comandos y edita — pero cada edición llega como un parche
• Acéptala, recházala, o acéptala hunk por hunk. Un checkpoint antes de cada turno
• Chat lee, Plan escribe un plan, Build edita. Tú eliges cuánto puede hacer
• Sin cuenta de Odete y sin servidores de Odete: habla directo con tu proveedor

SWIFT
• Un subconjunto de SwiftUI, interpretado y renderizado como SwiftUI real, en vivo mientras escribes
• O crea un paquete de Swift Playground y ábrelo en Swift Playgrounds para compilar

CINCO IDIOMAS
Português, English, Deutsch, Français y Español — las pantallas, la salida del terminal,
los mensajes de git y el idioma en que responde el agente. Por defecto sigue a tu iPad,
y cambia al instante en Ajustes.

TUS ARCHIVOS SON TUYOS
Los proyectos viven en la app Archivos, dentro de Odete, o en iCloud Drive. Ábrelos en Working Copy,
en Swift Playgrounds, en lo que sea. Sin lock-in, sin servicio de sync nuestro, sin telemetría, y
sin nada a lo que registrarse.
```
