## Description (4000)

```
Odete est un environnement de développement qui tourne entièrement sur ton iPad. Pas une session distante, pas un onglet de navigateur pointé sur la machine de quelqu’un d’autre : l’éditeur, le dépôt git, le terminal, le gestionnaire de paquets et le serveur web vivent tous sur l’appareil que tu as en main.

Ce qui veut dire que ça marche en avion, dans le métro, et partout où le réseau ne va pas.

ÉDITEUR
• Coloration syntaxique par tree-sitter, pour JavaScript, TypeScript, JSX, Swift, CSS, HTML, JSON, YAML, Markdown et SQL
• Marques git dans la gouttière — touches-en une pour ouvrir le hunk et l’abandonner
• Complétion à partir des mots de ton fichier, des chemins de ton projet et des snippets
• Lint pendant que tu écris, plus les vraies erreurs de syntaxe d’esbuild
• Onglets, vue scindée, vue diff, et visionneuses image, PDF et bases SQLite
• Le travail non enregistré survit à la fermeture de l’app

GIT, LE VRAI
• Un vrai dépôt par projet, sur libgit2 — pas un wrapper autour d’une API web
• Stage par fichier ou par hunk, commit, branch, merge avec résolution de conflits, stash
• Clone et push en HTTPS, blame, et historique par fichier
• Les pull requests GitHub dans l’app : ouvres-en une, lis-la, vérifie la CI, commente, merge
• Écris le message de commit à partir du diff stagé en une touche

TERMINAL
• Un vrai shell : pipes, redirections, &&, ||, ;, &, variables, contrôle des jobs, historique, Tab
• npm install sur le vrai registre, avec résolution semver et un vrai lock file
• npm run dev, node, npx, git, et les habituels ls, cat, grep, find
• Tout ce qui ouvre un port devient un job que tu peux lister et tuer

PREVIEW
• Ton serveur de dev, rendu dans un panneau à côté du code, rechargé à chaque enregistrement
• Vite, Astro, Next et Nest
• Viewports iPhone, iPad et bureau, la console de la page, et une touche vers Safari

UN AGENT DE CODE, À TES CONDITIONS
• Apporte ton propre compte : Claude, Codex, Grok, ou tout endpoint compatible OpenAI
• Il lit tes fichiers, lance des commandes et modifie — mais chaque modification arrive en patch
• Accepte, refuse, ou accepte hunk par hunk. Un checkpoint avant chaque tour
• Chat lit, Plan écrit un plan, Build modifie. Tu choisis jusqu’où il peut aller
• Pas de compte Odete et pas de serveurs Odete : il parle à ton fournisseur directement

SWIFT
• Un sous-ensemble de SwiftUI, interprété et rendu en vrai SwiftUI, en direct pendant que tu écris
• Ou fabrique un paquet Swift Playground et ouvre-le dans Swift Playgrounds pour compiler

CINQ LANGUES
Português, English, Deutsch, Français et Español — les écrans, la sortie du terminal,
les messages git et la langue dans laquelle l’agent répond. Odete suit ton iPad par défaut,
et change tout de suite dans les Réglages.

TES FICHIERS SONT À TOI
Les projets vivent dans l’app Fichiers sous Odete, ou dans iCloud Drive. Ouvre-les dans Working
Copy, dans Swift Playgrounds, dans ce que tu veux. Pas d’enfermement, pas de service de sync à
nous, pas de télémétrie, et rien à quoi s’inscrire.
```
