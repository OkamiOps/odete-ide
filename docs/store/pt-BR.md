## Descrição (4000)

```
A Odete é um ambiente de desenvolvimento que roda inteiro no seu iPad. Não é sessão remota, nem aba de navegador apontando para a máquina de outra pessoa: o editor, o repositório git, o terminal, o gerenciador de pacotes e o servidor web vivem no aparelho que está na sua mão.

O que quer dizer que funciona no avião, no metrô, e em qualquer lugar onde o sinal não chega.

EDITOR
• Realce por tree-sitter para JavaScript, TypeScript, JSX, Swift, CSS, HTML, JSON, YAML, Markdown e SQL
• Marcas do git na margem — toque numa para abrir o hunk e descartar
• Autocompletar com as palavras do arquivo, os caminhos do projeto e snippets
• Lint enquanto você digita, mais os erros de sintaxe de verdade do esbuild
• Abas, split, diff, e visualizadores de imagem, PDF e banco SQLite
• O que não foi salvo sobrevive a fechar o app

GIT, O DE VERDADE
• Um repositório real por projeto, sobre libgit2 — não é casca em cima de API web
• Stage por arquivo ou por hunk, commit, branch, merge com resolução de conflito, stash
• Clone e push por HTTPS, blame e histórico por arquivo
• Pull requests do GitHub dentro do app: abrir, ler, conferir o CI, comentar, mergear
• A mensagem de commit sai do diff staged com um toque

TERMINAL
• Um shell de verdade: pipes, redirects, &&, ||, ;, &, variáveis, jobs, histórico, Tab
• npm install contra o registro real, com resolução de semver e lock de verdade
• npm run dev, node, npx, git, e os ls, cat, grep e find de sempre
• Tudo que abre porta vira um job que você lista e mata

PREVIEW
• Seu dev server desenhado num painel ao lado do código, recarregando a cada save
• Vite, Astro, Next e Nest
• Viewport de iPhone, iPad e desktop, o console da própria página, e um toque para o Safari

UM AGENTE, NAS SUAS CONDIÇÕES
• Traga sua conta: Claude, Codex, Grok, ou qualquer endpoint compatível com a OpenAI
• Ele lê seus arquivos, roda comandos e edita — mas toda edição chega como patch
• Aceite, recuse, ou aceite hunk a hunk. Um checkpoint antes de cada turno
• Chat lê, Plan escreve um plano, Build edita. Você escolhe até onde ele vai
• Sem conta da Odete e sem servidor nosso: ele fala direto com o seu provedor

SWIFT
• Um subconjunto de SwiftUI, interpretado e desenhado como SwiftUI de verdade, ao vivo
• Ou um pacote Swift Playground, que abre no Swift Playgrounds para compilar

CINCO IDIOMAS
Português, English, Deutsch, Français e Español — as telas, a saída do terminal, as
mensagens do git e o idioma em que o agente responde. Segue o seu iPad por padrão, e
muda na hora nos Ajustes.

SEUS ARQUIVOS SÃO SEUS
Os projetos ficam no app Arquivos, dentro de Odete, ou no iCloud Drive. Abra no Working
Copy, no Swift Playgrounds, no que você quiser. Sem amarra, sem serviço de sincronia
nosso, sem telemetria, e sem nada para assinar.
```
